# 東方酔々夢

DxLibを用いて開発している東方二次創作の弾幕STGです。

---
## 特徴
- C++を用いたフルスクラッチ開発(DxLibによる描画・入力をベースに、オブジェクト管理やシーン遷移を実装)
- データ駆動型の弾幕システム
- ボスフェーズ・スペルカードシステム
- スペルプラクティスモード
- ボム・喰らいボム
- アイテムの上部回収システム
- ドット絵エディタ(開発途中)

---

### プレイヤ

- 高速・低速移動
- 前方ショット
- ホーミングショット
- 被弾・無敵時間
- 残機
- ボム


### ボス

- 複数フェーズ
- フェーズタイマ
- 通常攻撃・スペルカード
- HPゲージ
- 耐久スペルカード


### 実装済み要素

- 1面道中
- 1面道中ボス
- ボス
- ポーズ
- プラクティス
- コンティニュー
- ゲームオーバー
- ボム
- 喰らいボム
- 上部回収
- アイテムドロップ

### 弾幕
- 全方位弾
- NWay弾
- 自機狙い(Way数が偶数の場合は自機外し)
- 回転弾幕
- 複合弾幕


### シーン

- タイトル
- スペルプラクティス
- ステージ
- ゲームオーバー
- クリア
- ポーズ
- 終了確認


### 開発環境

- C++
- DXライブラリ
- Visual Studio 2022

開発途中ですが、現状は以下の内容を実装済みです。
