# 東方酔々夢

DxLibを用いて開発している東方二次創作の弾幕STGです。

---
## 主な特徴・システム
- **C++/DxLibによるフルスクラッチ開発**(描画・入力・オブジェクト管理を自作実装)
- 弾幕STGシステム
    - ボスフェーズ・スペルカード・耐久スペル
    - 喰らいボム、アイテム上部回収
    - 霊夢B(現状)のパワー連動ショット
- **プラクティス機能**
    - 各フェーズを個別練習可能なスペルプラクティスモード
- **ハイスコアランキング・ネームエントリー**(バイナリセーブ対応)

---

## 開発環境

- 言語　　　　　：C++
- 主要ライブラリ：DXライブラリ
- 開発環境　　　：Visual Studio 2022
