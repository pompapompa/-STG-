# 東方酔々夢

DxLibを用いて開発している東方二次創作の弾幕STGです。

---
## 主な特徴・システム
- **C++/DxLibによるフルスクラッチ開発**(描画・入力・オブジェクト管理を自作実装)
- 弾幕STGシステム
    - ボスフェーズ・スペルカード・耐久スペル
    - 喰らいボム、アイテム上部回収
    - 霊夢B(現状)のパワー連動ショット
- **プラクティス機能**
    - 各フェーズを個別練習可能なスペルプラクティスモード
- **ハイスコアランキング・ネームエントリー**(バイナリセーブ対応)

## 操作方法
| キー | 動作 |
|---|---|
| ↑ ↓ ← → | 移動 |
| Shift | 低速移動 |
| Z / Space | ショット（高速移動中のみホーミング弾を追加） |
| X | ボム（被弾直後の喰らいボムにも対応） |
| Esc | ポーズ |
| R | リトライ |
| Q | タイトルへ戻る |
| F | フルスクリーン／ウィンドウ切り替え |
| Z / Enter | メニューの決定 |
| X / Esc | メニューのキャンセル |

ランキングの名前入力はキーボードで行います（Backspaceで削除、Enterで確定）。
